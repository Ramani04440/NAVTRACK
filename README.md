
# NavTrack | Driving School Management System

NavTrack is a comprehensive Driving School Management System designed to streamline the entire learning and administrative process for driving schools. The platform enables students to register, schedule lessons, track progress, access learning materials, and manage bookings, while instructors and administrators can oversee schedules, student records, and operational workflows.

This project was developed as part of a full stack internship to demonstrate real-world application development involving authentication, scheduling, dashboard management, and responsive web design.

## 🚀 Key Features

### 👨‍🎓 Student Features
- Secure registration and login
- Personal profile management
- Upload required documents
- Book driving lessons
- Access learning materials
- Track lesson progress and schedules
- Reset forgotten passwords

### 👨‍🏫 Instructor Features
- View assigned students
- Manage lesson schedules
- Track student progress

### 👨‍💼 Admin Features
- Dashboard overview
- Student and instructor management
- Schedule monitoring
- Operational control

## 🗂️ Project Workflow

1. **Landing Page** – Introduction to the platform and available services
2. **Login** – Secure authentication for users
3. **Sign Up** – New account registration
4. **Personal Details** – Collection of user information
5. **Document Upload** – Upload identity and required documents
6. **Forgot Password** – Password recovery workflow
7. **Dashboard** – Central management panel
8. **Schedule** – Driving lesson scheduling
9. **Lesson** – Access lesson information
10. **Book Lesson** – Lesson booking system
